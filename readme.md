Auteur : Rodolphe NOUEL, Télécom SudParis FISE 2A

--> Ce projet consiste en un site communautaire de partage d'inventaire de caissons de basse (subwoofers).

Nomenclature du cahier des charges :
- [objet] : caisson de basse (`Subwoofer`)
- [inventaire] : collection (`SoundSystem`), une par membre
- [galerie] : vitrine (`Showcase`), association M-N avec les caissons
- membre : `Member`
